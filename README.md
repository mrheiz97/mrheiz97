## 👋 About

I'm **MrHeiz97**, the developer behind **StumpfWorks**.

I build open-source software, infrastructure tools and connected hardware — from identity and authentication systems to mobile applications, USB networking and embedded devices.

StumpfWorks is my growing ecosystem of independent projects, built around one simple idea:

> **Build it. Understand it. Own it.**

No mandatory cloud. No unnecessary vendor lock-in. Your infrastructure, your control.
